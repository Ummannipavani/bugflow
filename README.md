# 🐞 BugFlow

BugFlow is a modern bug tracking and project management system built using **FastAPI**, **SQLAlchemy**, **Jinja2**, **HTML**, **CSS**, and **JavaScript**. It enables teams to efficiently report, manage, prioritize, and track software issues through a clean and user-friendly interface.

---

## ✨ Features

- 🔐 User Registration & Login (JWT Authentication)
- 📊 Interactive Dashboard
- 🐞 Report New Issues
- ✏️ Edit and Delete Issues
- 📷 Upload Screenshots for Bugs
- 📁 Project Management
- 🔍 Search and Filter Issues
- 🚦 Priority & Severity Tracking
- 📅 Due Date Support
- 🔔 Deadline Notifications
- 🤖 AI-Powered Bug Description Improvement
- 📈 Recent Activity Tracking

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/bugflow.git
```

### Navigate to the project

```bash
cd bugflow
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
uvicorn app.main:app --reload
```

Open your browser and visit:

```
http://127.0.0.1:8000
```
